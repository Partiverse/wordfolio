# Wordfolio 0.1.0-beta.3 内测指引

欢迎参加 Wordfolio 内测！这是一个**义项级**背单词 App——同一个词的多个意思分开记，避免"认识这个词但不知道它在你那句话里是什么意思"。

- 版本：**0.1.0-beta.3**（Android，安装包约 36MB）
- 词库版本：v0.1-m1（499 词 / 2495 个义项）
- 分发方式：直接安装 APK（不走应用商店）

## 一、安装

1. 收到 APK 文件（`wordfolio-0.1.0-beta.3.apk`）后传到手机（微信文件传输助手 / QQ / 数据线均可）
2. 在文件管理器里点击该 APK，系统会提示"未知来源应用"，按提示允许**当前这个文件管理器**安装即可
3. 安装完成后桌面出现 "Wordfolio" 图标，点击打开

**系统要求**：Android 7.0 及以上的**arm64 架构**手机（2017 年后的主流机型基本都是；如果安装时提示"应用未安装"，多半是架构或系统版本问题，告诉我你的机型我帮你确认）。

## 二、怎么用（当前版本能做的）

| 功能 | 位置 | 说明 |
|---|---|---|
| 浏览词库 | 首屏 | 500 词双列网格，按词频排序；点卡片进详情 |
| 查词 | 首屏搜索框 | 英文词头（如 `run`）或中文释义（如「走」）都能搜；中文支持单字搜索 |
| 词性筛选 | 搜索框下方 | 按 n / v / adj 等词性过滤 |
| 收藏 | 卡片右上角 ☆ | 点击收藏；点「★ 收藏」chip 只看收藏过的词 |
| 发音 | 词条页 🔊、定义与例句文字 | 点击任意英文/中文文本朗读（系统 TTS 引擎） |
| **背单词** | **底部「学习」tab** | 每天 20 个义项的复习队列；翻卡看释义，按「重来/困难/一般/简单」四档反馈，系统按记忆曲线（FSRS）安排下次出现时间 |

## 三、当前版本的已知限制（重要，避免误判为 bug）

1. **没有例句**：词库 v0.1-m1 的例句表还没填充，词条详情只有中英释义。例句预计后续版本补上。
2. **没有 CEFR 等级筛选**：词库尚未标注难度等级（A1–C2），所以界面只提供词性筛选。
3. **只有 499 词**：目前是内测词库规模，非完整词书。
4. **背单词还在早期**：学习队列刚上线（M-B 第二版），每日目标可在「统计」tab 调 10/20/30/50，但**还不能调难度曲线**。请重点反馈：四档评分（重来/困难/一般/简单）的划分是否符合你的主观感受——这是整个调度算法唯一的输入，评得准不准直接决定复习节奏。
5. **无推送提醒**：应用不会主动提醒你今天该背了，得自己打开。
6. **发音依赖系统语音引擎**：如果手机没装/没启用语音引擎（如小米/华为部分机型），发音会不响——应用顶部会给出提示，装好引擎即可恢复。
7. **收藏与学习记录存在手机本地**：换手机或重装应用会丢失，正在做本地备份。
8. **仅 Android**：iOS 版本按项目决策暂停分发（见 ADR-0006）。

## 四、请你重点反馈什么

比起"好不好用"这类泛泛的问题，以下三类的信息对下一版最有价值：

1. **准确性（最重要）**：查到词条后发现**释义错了、词性错了、例句（若有）不搭**——请记下**词头 + 你认为正确的样子**。这是我们内容线要改的地方。
2. **中文搜索**：试试搜「走」「跑」「水」这类单字，再试试搜完整中文词，看结果是否够用、太多还是太少。
3. **手感**：四档评分按起来顺手吗、翻卡响应快不快、每日量够不够、筛选栏和底部 tab 好用吗、有没有卡顿或闪退（闪退请附手机型号与系统版本）。

另外也想知道：你希望 App 接下来先做**练习题型**（听音辨义/义项选择）还是**把学习闭环做深**（错题本、复习历史曲线、提醒推送）？

## 五、反馈方式

直接回复我（发消息或语音）即可，不用整理格式。**崩溃/闪退**最好附上：手机型号、系统版本、当时在做什么操作。

## 六、隐私说明

本应用**完全离线**，不联网、不收集任何数据、不申请定位/通讯录等权限。你的收藏和学习记录只存在你手机里。
